# 「消火ゲーム作って」って話しかけたら本当にゲームができた話

## 「コード書ける人じゃないと無理」は、もう昔の話かもしれない

Robloxでゲームを作りたいと思ったことはありますか？

でも「プログラミングできないし…」「Luauって何…」と思って諦めた方もいると思います。

私もゲームのアイデアは色々あるのに、コードを書くのが億劫で手が止まることが多くありました。

そんな中、**AI（Claude）とRoblox Studioを直接繋ぐ**方法を試したところ、開発のスタイルがガラッと変わりました。この記事ではその体験を紹介します。

---

## 実際にどんなことができるの？

こんな会話でゲームが作れます。

---

**私**：「家が燃えていて、プレイヤーが消火器で火を消すゲームを作りたい」

**AI**：「わかりました。まず火の広がり方を管理するスクリプトと、消火器の当たり判定を作りますね」

*（数秒後）*

**AI**：「スクリプトができました。Roblox Studioに反映してもいいですか？」

**私**：「うん、お願い」

*→ Studio に自動でスクリプトが反映される*

**AI**：「反映できました。テストプレイしてみてください」

---

これが実際の開発の流れです。「何を作りたいか」を日本語で伝えるだけで、AIがコードを書いてStudioに反映してくれます。

## 具体的な会話の例

### 機能追加のとき

> 「消火器を使ったら残量が減って、ゼロになったら使えなくなるようにして」

これだけでAIが残量管理のコードを追加してくれます。

### バグ修正のとき

> 「消火器を持ったまま車に乗ると、消火器が変な場所に表示される」

現象を言葉で説明するだけで、AIが原因を推測して修正します。

### 見た目の調整のとき

> 「火の色をもう少しオレンジっぽくして、煙も出るようにしたい」

パーティクルの設定もAIが調整してくれます。

## なぜこれが実現できるの？（超ざっくり説明）

従来の流れ：
```
アイデア → 自分でコードを書く → コピペ → Studioに貼り付け → テスト
```

AI連携後の流れ：
```
アイデアを話す → AIがコードを書いてStudioに直接反映 → テスト
```

**AIがエディタとRoblox Studioを直接繋いでいる**のがポイントです。コードを書く・コピペするという手間がなくなり、「作りたいもの」だけに集中できます。

---

## 「全部AIが作るなら自分は何もしなくていいの？」

いいえ、そうはなりません。

AIはあくまで「言われたことを実装する係」です。**何を作るか、どんな体験にしたいかを決めるのは人間**です。

実際に私がやっていること：

- ゲームの世界観・ルールを決める
- テストプレイして「ここが楽しくない」「これは難しすぎる」と判断する
- 「もっとこうしたい」という改善案を出す

AIは「実現する手段」を提供してくれますが、「何を作るか」というクリエイティブな部分は人間が担います。

## 実感したメリット

### ① アイデアをすぐ試せる

「こんな機能があったら面白いかも」という思いつきを、その日のうちに動くものとして確認できます。従来は「コードを調べて→書いて→デバッグして」という工程が必要でしたが、今は「話しかけて→テストプレイ」で済みます。

### ② 詰まらない

コードのエラーで作業が止まることがほぼなくなりました。エラーメッセージをAIに貼り付けて「これどういう意味？直して」と言えば解決してくれます。

### ③ Luauを知らなくても始められる

Luauはこういう文法で……という知識がなくても大丈夫です。「何がしたいか」を日本語で伝えれば、AIが適切なコードを書いてくれます。（ただし、作っていくうちに自然と基礎は身につきます）

## 正直なところ、難しかった部分も

### 最初のセットアップは少しだけ技術的

AIとStudioを繋ぐための初期設定が必要で、そこだけは多少調べる必要があります。ただ、設定できてしまえばあとはほぼ会話だけです。

👉 **[環境構築の詳しい手順はこちら（Zenn）](https://zenn.dev/kamezooo/articles/8752d4ebf93b42)**

### 複雑なゲームになるほど方向性の整理が必要

機能が増えてくると、AIへの指示が曖昧になりがちです。「何を・どういう状態にしたいか」を具体的に伝える力は多少必要になります。

### テストプレイは自分でやる必要がある

「楽しいかどうか」の判断はAIにはできません。テストプレイして感触を確かめて、改善点を言語化するのは人間の仕事です。
